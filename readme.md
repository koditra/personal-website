# Aashvik's Personal Website

My personal website where I show who I am, what I'm interested in, and the projects I've built.

## What's on it

- About me
- Projects I've built
- Links to my GitHub and projects
- San Jose local time
- Custom mouse cursor
- Responsive design for mobile

## Built With

- HTML
- CSS
- JavaScript

## Projects

Some of the projects currently featured on the site:

- **Anukrama** - Bhagavad Gita verse practice website with AI chanting evaluation
- **Gray Thief** - A grayscale Godot game about stealing light
- **Hackropad** - A custom 3-key RP2040 macropad with a custom PCB
- **Sudo Jago** - An alarm device that makes you fix Java bugs to wake up

## Run Locally


Clone the repository:

    git clone https://github.com/koditra/website.git

Then open `index.html` in your browser.
